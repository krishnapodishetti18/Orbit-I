# Orbit AI — Hackathon Presentation

## Seven-slide outline

1. **The operations gap** — instructions are scattered, deadlines slip, and planning takes time.
2. **Orbit AI** — natural language in; reviewed, actionable operations out.
3. **Live product** — dashboard, live task data, reminders, workflows, and analytics.
4. **Trustworthy AI pipeline** — backend-only API key, structured plan, validation, human approval.
5. **Technical architecture** — React/Vite, FastAPI, SQLAlchemy/SQLite, scheduler-ready reminders.
6. **Why it matters** — individuals and teams get execution clarity without losing control.
7. **Roadmap** — Firebase production verification, PostgreSQL, team collaboration, integrations.

## Two-minute demo script

“Operations work rarely arrives as a clean task list. It arrives as a message like: ‘Finish the presentation by Friday and remind me tomorrow.’ Orbit AI turns that instruction into a structured, reviewable plan.”

“This is the live dashboard. Every number is calculated from persisted data. The TriCity project already shows realistic deliverables, priorities, deadlines, a reminder, and a reusable workflow.”

“I’ll enter: ‘Create a high-priority task to finish the presentation by Friday.’ Orbit sends the instruction to the secure backend. The agent returns typed task data, but crucially it does not apply anything automatically.”

“Here is the preview. I can discard it or approve it. On approval, the task is saved to the database, appears in the task list, updates dashboard metrics, and records an activity event.”

“The same pattern supports reminders, recurring routines, project plans, and repeatable workflows. Orbit AI gives people an agent for operations, while keeping them in control of every consequential action.”
